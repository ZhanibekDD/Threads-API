Что мы храним в связи с интеграцией Threads

Аккаунт ZakonExpert (@zakonexpert.kzz) в Threads использует официальный Threads API от Meta для поиска публичных публикаций и, после проверки сотрудником, ответа на отдельные из них. В связи с этим мы храним:

  • Токен доступа Threads (OAuth) — техническая учётная запись самого аккаунта ZakonExpert, не данные посторонних пользователей. Хранится в закрытой базе данных на нашей стороне, не публикуется и не передаётся третьим лицам.
  • Тексты и ссылки найденных публичных публикаций Threads — только те посты, которые уже опубликованы автором открыто (публично) и найдены по ключевым словам, связанным с юридическими/финансовыми проблемами в Казахстане (например, арест счёта, действия ЧСИ). Сохраняются: текст поста, автор (публичный username), ссылка (permalink), дата публикации.
  • Черновики ответов — тексты, сгенерированные для возможного ответа на найденный пост, вместе с оценкой релевантности. Не публикуются без подтверждения сотрудника ZakonExpert.
  • Журнал действий — какие посты были найдены, кем и когда одобрен или отклонён черновик, что было опубликовано (без содержимого токенов и паролей).

Чего мы не делаем

  • Не собираем закрытые (приватные) публикации.
  • Не публикуем ответы без ручной проверки сотрудником.
  • Не передаём найденные данные третьим лицам, кроме сервиса анализа DeepSeek (используется только для оценки релевантности и черновика ответа, без передачи ИИН и других персональных данных клиентов).
  • Не запрашиваем ИИН или документы в публичных комментариях — только в WhatsApp, после того как человек сам обращается за консультацией.

Отзыв доступа приложения ZakonExpert к вашему Threads-аккаунту

Если вы предоставляли приложению ZakonExpert доступ к своему Threads- аккаунту (например, как тестировщик на этапе разработки), вы можете отозвать этот доступ самостоятельно в любой момент: Threads → Настройки → Аккаунт → Сайты и приложения (Websites and apps) → найдите «Threds»/ZakonExpert → «Удалить».

После отзыва доступа наше приложение теряет возможность выполнять любые действия от имени вашего аккаунта; уже сохранённые у нас технические данные (если применимо) удаляются по запросу, как описано выше.
